# VCO concepts

Standalone GitHub Pages export of VCO concepts, version 2.

## Publish

1. Create a new GitHub repository (public if using GitHub Free).
2. Unzip this archive. Upload its contents directly into the repository root, so index.html is at the top level alongside assets/, clarity/, layers/ and the other folders. Upload the extracted files, not the ZIP itself.
3. Open Settings → Pages. Select Deploy from a branch, then main and /(root), and Save.
4. Leave Custom domain blank. When deployment finishes, use the URL shown in Pages settings.

For a repository named vco under mpdub, the expected address is https://mpdub.github.io/vco/.

All links and assets are relative, so any repository name works. No build, installation, API keys or server are required. The original artwork and presentation are preserved.
